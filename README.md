### Hey, I'm Sebastian

I'm a systems and platform engineer in Buenos Aires. I build and run the
infrastructure other engineers deploy onto, usually from inside their team,
working with Kubernetes, Terraform, CI/CD, and observability.

Lately I've been building tools for coding agents: integrations for pi,
shared tool definitions for MCP, worktree automation, and benchmarks for
agent memory. I write about that work at [feniix-hq.net](https://feniix-hq.net).

#### Contributing to
